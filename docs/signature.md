# Binary signature

mnuカーネルでは、バイナリ署名を使用して、カーネルモジュールやユーザーランドのバイナリが改ざんされていないことを検証します。
署名は、公開鍵暗号方式を用いて行われ、署名されたバイナリは、対応する公開鍵を使用して検証されます。

カーネルは実際の署名をデータベースに基づいて検証することのみを行います。
署名の検証に失敗した場合は、バイナリのロードを拒否します。

Signature DBの更新などに必要なケーパビリティ配下のとおりです。

- `signature.db.write`: signature DBの書き込み権限
- `signature.db.read`: signature DBの読み取り権限

データベース登録と読み取りにはIPCを使用します。
